# 炼金炉 · 全页面 UX 走查报告

日期：2026-11-09 ｜ 版本：v=20261109-p9 ｜ 走查范围：6 个视图 + 4 个弹窗 + 全部关键交互流
维度：信息架构 · 用户流程 · 操作效率 · 反馈机制 · 视觉层级 · 组件一致性

---

## 一、总体评价

信息架构骨架是健康的：首页（模式入口）→ 项目工作台（资产）→ 框架工作台 ①（结构）→ Topic 工作台 ②（产出）→ Skill / AI 配置（支撑），编号导航与真实创作顺序一致，认知负担低。本地优先、数据可解释（data/ 目录透明）符合目标用户的信任预期。

主要短板集中在**反馈机制**（长任务、错误提示）和**一致性**（图标体系、确认方式、忙碌状态）两栏。核心创作流程（建项目 → 上材料 → 生成框架 → 生成 Topic → 审核 XML）路径通畅，但中途失败的恢复路径依赖用户自己理解错误文字。

## 二、已修复（本轮，P1）

## 三、待办方案（按优先级排序）

### P2 · 建议下一轮就做

1. **导航图标体系不统一**（一致性）
   现状：⌂ ▣ ① ② ✦ ◌ 六个字形来自不同符号家族（几何、圈码、星号、圆圈）。
   方案：统一为一套线性图标（内联 SVG，stroke 风格），或全部降级为"01/02/03"编号 + 文字。工作量小，观感提升明显。

2. **忙碌状态无视觉反馈**（反馈）
   现状：AI 生成时按钮只 disabled，无 spinner、无文案变化（仅消息区文字提示）。
   方案：给 `setBusyButtons` 加 `.is-busy` 类：按钮内置 CSS 转圈动画 + 保留文字。纯 CSS，一处改动全局生效。

3. **删除确认用原生 window.confirm**（一致性）
   现状：删材料/删项目弹系统原生对话框，与应用纸质风格脱节，且原生框在 pywebview 下样式更突兀。
   方案：做一个通用 `<dialog id="confirm-dialog">`（标题 + 描述 + 取消/确认红色按钮），替换两处 confirm 调用。

4. **分析工作台单一消息区过载**（反馈）
   现状：上传材料、粘贴文本、Excel 导入、框架生成、删除材料等 8+ 操作共用 `#analysis-message` 一条消息，互相覆盖，用户可能错过关键结果。
   方案：材料区操作就地反馈（材料卡片上闪一条 2 秒的轻提示），框架区操作留给 analysis-message；或升级为右上角 toast 栈（可堆叠 3 条）。

### P3 · 排期做

5. **弹窗不支持点击遮罩关闭**：四个 dialog 只能按钮/Esc 关闭。加 backdrop click → close（注意表单弹窗要防误触，可只对 cover-preview / framework-topic 预览类开启）。
6. **书架空状态缺行动入口**："还没有项目"没有"＋ 新建项目"按钮，用户要多想一步去哪建。空状态内直接放按钮。
7. **搜索无快捷键**：书架页支持 `/` 或 Cmd+F 聚焦搜索框；书架卡片支持 Enter 打开（已是 button，天然支持，验证即可）。
8. **长任务进度感知**：框架/Topic 生成只有文字消息轮询；批量并行已有逐节点状态。可给单项生成加不确定进度条（CSS 动画即可），降低"卡死了吗"焦虑。
9. **detail 页 Topic 树点击展开 XML 后无面包屑**：展开的编辑器出现在页面下方，长列表时用户不知发生了什么。展开时 scrollIntoView + 高亮闪一下。

### P4 · 观察项

10. 首页 hero 与模式卡的"创建项目"双入口并存，新用户可能困惑两者差别——观察真实使用，若困惑率高，把 hero 大按钮改为滚动到模式卡。
11. 设置页 12 个输入项较多，已有档案分组；可考虑把"高级参数"折叠。
12. 窗口极窄（<900px）时框架工作台左右栏挤压，媒体查询已有基础处理，偶尔真机用一下确认。

## 四、做得好的（保持）

- 视图编号 ①② 与创作顺序一致；面包屑实时跟随视图切换
- 表单校验就地报错（Topic 标题为空、封面超 8MB 等），文案具体
- 危险操作有确认 + 后果说明（"原始文件和提取文本都会被删除"）
- 生成任务可取消（取消生成按钮 + Job 取消 API 打通）
- 键盘可达性基础在位：模式卡有 tabindex/keydown，搜索框有 aria-label
- 撤销/重做 + 历史版本下拉，框架编辑有后悔药

## 五、验证清单（本轮修复后请真机过一遍）

1. 进详情 → 点侧栏"项目工作台" → 应回书架
2. 进详情 → 回首页 → 点任一模式卡 → 应回书架且筛选生效
3. 拔掉后端（或等超时）做任意操作 → 应见中文连接失败提示
4. 任意成功操作（保存材料等）→ 6 秒后消息自动消失；错误消息保留
